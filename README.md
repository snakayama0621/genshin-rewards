# genshin-rewards

原神のHoYoLABログインボーナスの受取と、交換コードの引き換えを自動化する個人用のChrome拡張機能（Manifest V3）です。ブラウザでログイン済みのHoYoLABと公式交換サイトのセッションをそのまま使い、外部サーバーは使いません。

非公式のツールです。HoYoverse / COGNOSPHERE とは関係ありません。自動実行は利用規約上のリスクがあるため、既定でオフにしています（[利用規約との関係](#利用規約との関係)）。

## 機能

### ログインボーナス

- 毎日のログインボーナスを、指定した時刻に自動で受け取る
- ポップアップの **今すぐ受取** で手動で受け取る
- 当日の受取状況（受取済み、未受取、要認証、要ログイン、失敗）を表示する
- 受取済みと記録した日は、APIを呼ばずに処理を終える
- Chromeが止まっていて予定時刻を過ぎた場合は、次回の起動時に当日の状況を確認し、未受取なら受け取る
- 失敗したときは30分後に再試行する（1日3回まで）。CAPTCHAが出たら自動処理を止める

### 交換コード

- 交換コードの定期確認を「オフ」「新しいコードを通知」「自動で引き換え」から選ぶ
  - 新しいコードを通知: 公開のコード一覧（`hoyo-codes.seria.moe`）だけを取得し、前回の一覧になく、まだ引き換えていないコードをデスクトップ通知で知らせる。HoYoverse / HoYoLAB へは通信しない
  - 自動で引き換え: まだ引き換えていないコードを自動で引き換える
- ポップアップの **今すぐ確認** で手動で引き換える（定期確認の設定にかかわらず引き換える）
- コードを入力して1件だけ引き換える
- コードごとの結果（引き換え済み、使用済み、期限切れ、無効、上限到達、対象外の地域、冒険ランク不足、失敗）をUIDごとに記録し、同じコードを二度送らない
- 失敗したコードは3回まで再試行する

### アカウント

- HoYoLABと公式交換サイトのログイン状態を表示し、ログインが切れたら通知する
- UID、プレイヤー名、サーバー、冒険ランクを表示し、UIDをコピーできる
- 複数のサーバーにキャラクターがいる場合は、交換コードを引き換えるキャラクターを選べる

### 履歴・通知・設定

- 実行日時、処理、契機、結果、メッセージ、交換コードを履歴に残す（300件、30日まで）。通知モードの確認は、成功したときは履歴に残さない
- 通知は「ログボ受取成功」「コード引き換え成功」「失敗」「ログイン切れ」を個別にオン・オフできる。新しいコードの通知は、定期確認で「新しいコードを通知」を選んでいれば常に出る
- ログボの実行時刻と、交換コードの確認間隔（1、3、6、12、24時間）を設定できる
- 前回の実行日時と次回の予定日時を表示する
- 日本語表示、ライトモードとダークモード、狭い画面幅に対応する

## アーキテクチャ

```
ポップアップ / 設定画面（ストレージは読み取りのみ）
    │ コマンド（chrome.runtime.sendMessage）      ▲ chrome.storage.onChanged
    ▼                                             │
Service Worker（background/index.ts はイベントの登録だけ）
    ├─ commands.ts    コマンドの検証と振り分け
    ├─ scheduler.ts   アラームの計算と登録、起動時の取りこぼし判定
    ├─ checkin.ts     ログボ受取
    ├─ redeem.ts      交換コード引き換え
    ├─ account.ts     キャラクター一覧と対象選択
    ├─ session.ts     ログイン状態とログイン切れ通知
    ├─ notify.ts      通知
    ├─ history.ts     履歴
    └─ api/           HTTP（タイムアウト、再試行、送信間隔）、HoYo API、交換コード取得元
```

- API通信、スケジューリング、ストレージ、UI、通知を別のモジュールに分けています。
- HoYoLAB / HoYoverse のURL、パラメータ、retcode の分類は `src/background/api/hoyo.ts` の表にまとめてあります。APIの仕様が変わったら、この表を直します。
- ストレージに書き込むのは Service Worker だけです。書き込みは1本のキューで順番に処理します。
- 手動実行と自動実行が重なった場合、2つ目は実行中の処理の結果を受け取ります。同じ処理は同時に1つしか動きません。
- ログボと交換コードの処理は互いに独立しています。

API仕様の根拠、各処理の手順、制限値は [docs/DESIGN.md](docs/DESIGN.md) にあります。

## セットアップ

Node.js 22.13 以上が必要です。

```sh
npm ci
```

## ビルド

```sh
npm run build
```

`dist/` に拡張機能ができます。型チェック、Lint、テスト、ビルドをまとめて実行するには `npm run check` を使います。

## Chromeへのインストール

1. `npm run build` を実行する。
2. Chromeで `chrome://extensions` を開く。
3. 右上の **デベロッパーモード** をオンにする。
4. **パッケージ化されていない拡張機能を読み込む** を押し、`dist` フォルダを選ぶ。
5. ツールバーの拡張機能メニューから **原神 報酬自動受取** をピン留めする。

コードを更新したら、`npm run build` の後に `chrome://extensions` で拡張機能の再読み込みボタンを押します。

## 使い方

1. 同じChromeプロファイルで、[HoYoLAB](https://www.hoyolab.com/) にログインする。ログボの受取に使います。
2. 同じプロファイルで、[公式交換サイト](https://genshin.hoyoverse.com/ja/gift) にもログインする。交換コードの引き換えに使います。HoYoLABとは別のログインです。
3. ツールバーのアイコンを押してポップアップを開く。キャラクターとログイン状態が表示されます。
4. **今すぐ受取** でログボを、**今すぐ確認** で交換コードを手動で処理する。
5. 自動で処理するには、設定画面の「利用上の注意」を読んでから、ポップアップか設定画面で **自動受取** をオンにし、**定期確認** を選ぶ。変更した時点で、実行すべき処理があればすぐに実行します。
   - 新しいコードを知るだけでよい場合は **新しいコードを通知** を選び、通知が来たら **今すぐ確認** で引き換えます。この設定の定期確認は公開のコード一覧を読むだけで、HoYoverse には何も送りません。
   - **新しいコードを通知** から **自動で引き換え** に切り替えると、確認間隔を待たずにすぐ引き換えます。

設定画面はポップアップの歯車ボタンから開きます。実行時刻、確認間隔、通知、対象キャラクター、交換コードの一覧、すべての履歴を扱えます。

ログボの日付は UTC+8 の 0:00（日本時間 1:00）に切り替わります。実行時刻はPCのローカル時刻で指定し、各日付の中でその時刻が来たときに実行します。

## 外部通信先と権限

### 通信先

| 通信先                                | 用途                                                | Cookie   |
| ------------------------------------- | --------------------------------------------------- | -------- |
| `sg-act-public-api.hoyolab.com`       | ログボの状況確認と受取（公式ログボページと同じAPI） | 送る     |
| `api-account-os.hoyolab.com`          | キャラクター一覧の取得                              | 送る     |
| `api-account-os.hoyoverse.com`        | キャラクター一覧の取得（公式交換サイトと同じAPI）   | 送る     |
| `public-operation-hk4e.hoyoverse.com` | 交換コードの引き換え（公式交換サイトと同じAPI）     | 送る     |
| `hoyo-codes.seria.moe`                | 有効な交換コードの一覧の取得                        | 送らない |

これ以外のホストへの通信は、manifest の CSP（`connect-src`）でブラウザが拒否します。アクセス解析やテレメトリーはありません。

### 権限

| 権限                              | 理由                                             |
| --------------------------------- | ------------------------------------------------ |
| `storage`                         | 設定、受取状況、コードの記録、履歴を保存する     |
| `alarms`                          | 決まった時刻と間隔で処理を起動する               |
| `notifications`                   | 成功、失敗、ログイン切れ、新しいコードを通知する |
| `host_permissions`（上の5ホスト） | Service Worker から各APIへ通信する               |

`cookies`、`tabs`、全サイトへのアクセスは要求しません。

## セキュリティ

- ID、パスワード、Cookie、トークンを読まず、保存も送信もしません。認証は `fetch` の `credentials: "include"` でブラウザが付けるCookieに任せます。拡張機能のコードからCookieの値は見えません。
- 交換コードの取得元には Cookie を送りません（`credentials: "omit"`）。
- APIの応答、コード一覧、ストレージの値、画面からのコマンドは、Zodで検証してから使います。交換コードは公式交換サイトと同じ形式（半角英数字30文字以内）のものだけを送ります。
- 画面は `textContent` と DOM API だけで組み立てます。`innerHTML` などは ESLint でエラーにしています。リンク先と通知のクリック先は、コード内の固定のURL表から選びます。
- 外部のJavaScriptは読み込まず、`eval` も使いません（MV3、CSP、ESLint で禁止）。
- CAPTCHAが出たら自動処理を止め、通知します。
- リクエスト数は次の値で抑えます。
  - タイムアウトは15秒です。
  - 再試行は GET だけで、最大2回です。
  - 同じホストへの送信は1秒以上あけます。
  - 交換コードは6秒間隔で、1回の実行につき最大10件です。
  - キャラクター一覧の取得は60秒に1回までです。
- ログには retcode と分類だけを出し、応答本文、UID、ヘッダーは出しません。

## 利用規約との関係

原神利用規約（最終更新 2026年8月12日）第9条1項20号は、次の行為を禁止しています。

> 外部ツール(BOT)もしくはCOGNOSPHERE PTE. LTD. から公式に提供していないプログラムを使用し、自分が有利にゲーム進行し、もしくは正常なサービス利用を妨げる行為。

全プレイヤーが手動で受け取れる報酬の受取を自動化することがこれに当たるかは、規約に書かれていません。違反と判断された場合、第9条2項により警告、利用停止、報酬の取消しがあり得ます。この拡張機能は次のように作っています。

- 自動実行は既定でオフにし、利用者が有効にしたときだけ動かす
- 交換コードの定期確認で「新しいコードを通知」を選んだ場合は、公開のコード一覧（`hoyo-codes.seria.moe`）を読むだけで、HoYoverse / HoYoLAB へは何も送らない。引き換えは利用者が **今すぐ確認** を押したときだけ行う
- 公式Webページが送るものと同じリクエストだけを送る。アプリの署名の偽装やゲームクライアントの模倣はしない
- CAPTCHAが出たら止める
- 送信頻度を手動操作と同程度に抑える

自動実行を使うかは利用者が判断してください。手動ボタンだけでも使えます。

## 既知の制限

- ログボの受取リクエストにUIDが含まれないため、報酬を受け取るキャラクターは選べません。HoYoLAB側の仕様で決まります。
- 交換コードの引き換えには、HoYoLABとは別に公式交換サイトへのログインが必要です。
- 交換コードは `hoyo-codes.seria.moe` から取得します。個人が運営する公開APIのため、停止や更新の遅れがあり得ます。そのときは手動入力で引き換えてください。
- 取得元は地域限定のコードを見分けられません。対象外の地域のコードは「対象外の地域」として記録され、再送しません。
- Chromeが起動していない間は動きません。PCのスリープ中に過ぎた予定は、復帰後に実行します。
- 1つのChromeプロファイルでは、ログイン中の1アカウントだけが対象です。複数のアカウントを使う場合は、Chromeのプロファイルを分けてそれぞれにインストールします。
- 対象は海外版（`hk4e_global`）だけです。中国版（miHoYo）には対応しません。
- 公式APIの仕様が変わると動かなくなります。修正箇所は `src/background/api/hoyo.ts` の表です。
- バンドルにZodが含まれるため、各JSファイルは約780KBです。

| 症状                                         | 確認すること                                                                                                                                                                                                                                                                                                         |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「要ログイン」「未ログイン」のまま変わらない | 同じChromeプロファイルでHoYoLAB（ログボ）と公式交換サイト（交換コード）にログインしているか。ログイン後にポップアップを開き直してください。                                                                                                                                                                          |

| キャラクターが表示されない                   | 直前の取得から60秒以内は再取得しません。1分ほど待ってからポップアップを開き直してください。                                                                                                                                                                                                                                 |

| 自動実行されない                             | 自動受取がオンか、定期確認がオフ以外か、設定画面の「次回予定」に時刻が出ているかを確認してください。Chromeが起動していないと動きません。                                                                                                                                                                             |
| 動作を詳しく調べたい                         | `chrome://extensions` で拡張機能の **Service Worker** を開き、コンソールの警告とエラーを確認してください。retcode と分類だけが出ます。                                                                                                                                                                               |
