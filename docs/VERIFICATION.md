# 実アカウントでの動作確認

自動テストでは確かめられない、ログイン済みアカウントでの動作を手動で確認する手順です。自分のアカウントに実際にリクエストを送るため、ログボの受取や交換コードの引き換えが本当に行われます。

## 準備

1. `npm run build` を実行し、README の手順で `dist` を Chrome に読み込む。
2. 同じプロファイルで [HoYoLAB](https://www.hoyolab.com/) と [公式交換サイト](https://genshin.hoyoverse.com/ja/gift) にログインする。
3. `chrome://extensions` で拡張機能の **Service Worker** を開き、コンソールを表示したままにする。

ストレージの中身は、Service Worker のコンソールで次を実行すると見られます。

```js
await chrome.storage.local.get(null);
```

## 確認項目

各項目の「期待する結果」と実際の結果を比べ、表の「結果」に OK か NG を記入します。NG のときは、コンソールの警告（`hoyo retcode ...`）と履歴のメッセージを控えてください。

| #   | 操作                                                                                                 | 期待する結果                                                                                                                                                                                                                                                | 結果 |
| --- | ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 1   | ポップアップを開く                                                                                   | キャラクター名、UID、サーバーが表示される。HoYoLAB と交換サイトのログイン状態が「ログイン中」か「未確認」になる                                                                                                                                             |      |
| 2   | **UIDをコピー** を押し、別の場所に貼り付ける                                                         | UID が貼り付けられる                                                                                                                                                                                                                                        |      |
| 3   | 当日未受取の状態で **今すぐ受取** を押す                                                             | 「受取済み」になり、今月の日数が1増える。ゲーム内メールに報酬が届く。HoYoLAB のログイン状態が「ログイン中」になる                                                                                                                                           |      |
| 4   | 続けて **今すぐ受取** を押す                                                                         | 通信せずに「本日は受取済みです」と表示される（コンソールに新しい `hoyo retcode` が出ない）                                                                                                                                                                  |      |
| 5   | 公式ログボページで当日分を受け取った後、翌日に **今すぐ受取** を押す（3 の代わりに確認してもよい）   | 「受取済み」になり、履歴の結果が「スキップ」になる                                                                                                                                                                                                          |      |
| 6   | **今すぐ確認** を押す                                                                                | 交換コードの件数が表示され、未使用のコードが6秒間隔で引き換えられる。履歴にコードごとの結果が残る                                                                                                                                                           |      |
| 7   | 引き換え済みのコードを手動入力して **引き換え** を押す                                               | 通信せずに「引き換え済み」と表示される                                                                                                                                                                                                                      |      |
| 8   | ゲーム内で使用済みだが拡張機能に記録のないコードを手動入力する                                       | 「使用済み」と記録される                                                                                                                                                                                                                                    |      |
| 9   | キャラクターが複数のサーバーにいる場合、ポップアップで別のキャラクターを選んで **今すぐ確認** を押す | 選んだキャラクターの UID とサーバーで引き換えられる（設定画面の交換コード一覧で確認）                                                                                                                                                                       |      |
| 10  | 自動受取をオンにし、実行時刻を数分後にして待つ                                                       | 時刻になると自動で受け取る（当日未受取の場合）。設定画面の「次回予定」が翌日の時刻に変わる                                                                                                                                                                  |      |
| 11  | 自動受取をオンにしたまま Chrome を終了し、実行時刻を過ぎてから起動する                               | 起動直後に当日分を受け取る（当日未受取の場合）。履歴の契機が「起動時」になる                                                                                                                                                                                |      |
| 12  | 定期確認を「自動で引き換え」にする                                                                   | 変更した直後に一度実行され、その後は設定した間隔で実行される                                                                                                                                                                                                |      |
| 13  | 通知の設定をすべてオンにして 3、6 を行う                                                             | 成功の通知が出る。各種類をオフにすると出なくなる                                                                                                                                                                                                            |      |
| 14  | HoYoLAB からログアウトして **今すぐ受取** を押す                                                     | 「要ログイン」になり、ログイン切れの通知が1回だけ出る。通知を押すと HoYoLAB が開く                                                                                                                                                                          |      |
| 15  | 公式交換サイトからログアウトして **今すぐ確認** を押す                                               | 交換サイトが「未ログイン」になり、ログイン切れの通知が出る。通知を押すと公式交換サイトが開く                                                                                                                                                                |      |
| 16  | サードパーティCookieをブロックする設定にして 3 を行う                                                | 失敗する場合は README のトラブルシューティングの対処で直ることを確認する                                                                                                                                                                                    |      |
| 17  | Service Worker の DevTools の Network を開いたまま、定期確認を「新しいコードを通知」にする           | 直後に一度確認し、未引き換えのコードがあれば「新しい交換コード」の通知が出る。通知を押すと公式交換サイトが開く。通信先は `hoyo-codes.seria.moe` だけで、履歴に交換コードの行が増えない。間隔を1時間にして次の確認を待つと、新しいコードがなければ通知しない |      |
| 18  | 17 の後、定期確認を「自動で引き換え」に切り替える                                                    | 確認間隔を待たずにすぐ引き換えが始まる                                                                                                                                                                                                                      |      |

CAPTCHA は意図的に発生させられません。発生した場合は、自動処理が止まり、失敗の通知が出て、通知から公式ログボページが開くことを確認してください。

## 結果の反映

確認が終わったら、README の「動作確認の状況」の表を更新します。応答の形式が想定と違った場合は、`src/background/api/hoyo.ts` の該当スキーマと、`src/testing/hoyo-replies.ts` の固定データを実際の応答に合わせて直します。
